Example 3: SCSS


//<---- Mixins ---->\\

@mixin font-basic($family) {
    font-family: $family;
    font-style: normal;
    font-weight: 400;
    font-display: swap;
}

//<---- CSS Code for the Main Content of the Page ---->\\

@import 'mixins.scss',
        'variables.scss',
        'header.scss',
        'sidebar.scss',
        'form.scss';

@font-face {
    @include font-basic('Poppins');
    src: url(fonts/Poppins/poppins-v15-latin-regular.woff2) format("woff2");
}

@font-face {
    @include font-basic('icomoon');
    src: url(../fonts/Icomoon/icomoon.ttf) format("truetype"),
        url(../fonts/Icomoon/icomoon.woff) format("woff");
}

Here in this example is SCSS code of the use of mixins and include functions. They allow code to become tidier and easier to read and edit, it also helps developers to stop repeating code as they can use a mixin instead.
